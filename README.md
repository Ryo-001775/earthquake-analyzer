Japan Earthquake Analyzer
Python data analysis project using real earthquake records from Japan.

Overviwe
his project analyzes 8,524 earthquake events using:

Pandas
NumPy
Matplotlib


Features

Earthquake statistics
Monthly earthquake counts
Yearly earthquake counts
Largest earthquake detection
Top 10 earthquakes
Magnitude distribution
Depth distribution
Earthquake location map
Depth vs Magnitude correlation


Results

Dataset

8,524 earthquake records
Years covered: 2000–2026
The geographical scope is N:39,S:35  
E:143,W:138


Key Findings

The largest earthquake was the 2011 Great Tohoku Earthquake (M9.1).
Earthquake activity peaked in 2011 due to the Great East Japan Earthquake and its aftershocks.
Correlation between depth and magnitude was weak (-0.174).
